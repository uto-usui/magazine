# 文体・表記スタイルガイド

このドキュメントは、AI生成文章（ニュースレター、記事キュレーション、要約など）における文体・表記ルールを定義します。

## 基本姿勢

- **柔らかく、自然体で** - 硬い言葉や気取った表現は避ける
- **押しつけない** - 読者に判断を委ね、煽らない
- **誠実に、等身大で** - 大げさに盛らない、賢く見せようとしない

## 2. トーンの使い分け・文脈に応じた表現

文脈と組み合わせる言葉によって、適切な表現を選ぶ。

### 肯定的な形容

| 表現 | 使う場面 | 例 |
|------|----------|-----|
| 優れた | 堅い名詞と組み合わせる | 優れたUX、優れた組織、優れた設計 |
| いい | 柔らかい名詞と組み合わせる | いい雰囲気、いい温度感、いいバランス |
| すごい・すばらしい・最高 | 編集部コメントなど口語調パート | 「これはすごい」「すばらしい記事」 |

※ 本文では「すごい」「最高」などカジュアルな表現は避け、「優れた」「効果的な」などを使う

## 3. 文体ルール

### 基本スタイル

- **文末**: 「です・ます」調（敬体）を基本とする
- **トーン**: 親しみやすく、専門的すぎない
- **主語**: 「私」「私たち」「筆者」「著者」は使わない。文脈で理解できる主語は省略する

### 語尾のバリエーション

単調な文章を避けるため、語尾を適度に変化させる。

```
✅ 良い例:
- 〜です。
- 〜ます。
- 〜でしょう。
- 〜かもしれません。
- 〜ですね。
- 〜になります。
- 〜といえます。

❌ 避ける:
- 同じ語尾が3回以上連続
```

### 一文の長さ

- 一文は **60〜80文字程度** を目安に
- 長くなる場合は文を分割する

### 段落構成

- 一段落は **2〜4文** を目安に
- 話題が変わるときは段落を分ける

## 4. 用語・表記統一

### 記号・句読点

| 用途 | 使用する | 使用しない |
|------|----------|------------|
| 句点 | 。 | ．（ピリオド） |
| 読点 | 、 | ，（カンマ） |
| 括弧 | 「」（引用・強調） | ""（ダブルクォート） |
| 括弧 | （）（補足） | ()（半角） |
| 三点リーダー | …（1文字） | ...（ピリオド3つ） |
| 中黒 | ・ | ･（半角） |
| ダッシュ | ー（長音） | −（マイナス） |

### 数字

- 桁数の多い数字: **半角数字 + カンマ区切り**（例: 1,000人）
- 日付: **YYYY/MM/DD**
- 時刻: **HH:MM**（24時間表記）
- 割合: **〇〇%**（半角）

## 5. NGワード・禁止表現

### 絶対に使わない表現

| NGワード | 理由 | 代替表現 |
|----------|------|----------|
| 「革命的」「画期的」 | 大げさ・陳腐 | 「新しいアプローチ」「注目の手法」 |
| 「爆速」「爆上げ」 | カジュアルすぎる | 「高速」「大幅に向上」 |
| 「神」「最強」 | カジュアルすぎる | 「優れた」「強力な」 |
| 「ぶっちゃけ」 | 口語的すぎる | 「実際のところ」「正直なところ」 |
| 「めっちゃ」 | 口語的すぎる | 「非常に」「とても」 |
| 「いわゆる」の多用 | 冗長 | 必要なときのみ使用 |
| 「基本的に」の多用 | 冗長 | 削除するか具体化 |
| 「必見」 | 煽り・押しつけがましい | 「注目」「おすすめ」「参考になる」 |
| 「劇的」 | 大げさ・広告的 | 「大きく」「明確に」 |
| 「核心」 | 硬い・仰々しい | 「ポイント」 |
| 「特筆」 | 硬い・堅苦しい | 「とくに」「際立つ」 |
| 「懸念」 | 硬い・ネガティブ | 「課題」「気になる点」 |
| 「執着」 | 強すぎる・ネガティブ | 「こだわり」「重視」 |
| 「慧眼」 | 気取っている・硬い | 「鋭い視点」「よく見ている」 |
| 「注目すべき」 | 押しつけがましい | 「注目の」「興味深い」 |
| 「劣悪」 | 強すぎる・ネガティブ | 「良くない」「問題がある」 |
| 「〜すべき」 | 押しつけがましい・ネット民的 | 「〜するとよい」「〜がおすすめ」 |

### 避けなければいけない表現

| 避ける表現 | 理由 | 代替表現 |
|------------|------|----------|
| 「〜することができます」 | 冗長 | 「〜できます」 |
| 「〜を行う」 | 冗長 | 動詞に置き換え（「実行する」「作成する」） |
| 「〜という形になります」 | 冗長 | 「〜になります」「〜です」 |
| 「〜させていただきます」 | 過剰敬語 | 「〜します」「〜いたします」 |
| 「〜の方」（不要な場合） | 冗長 | 削除 |
| 「現時点では」 | 冗長な場合が多い | 「現在」「今は」 |
| 二重敬語 | 不自然 | 適切な敬語に |

### 注意が必要な表現

| 表現 | 注意点 |
|------|--------|
| 「簡単」「容易」 | 読者によっては難しい場合も。「比較的」を付けるか具体化 |
| 「誰でも」「すべての人」 | 実際には例外がある場合が多い |
| 「必ず」「絶対に」 | 例外がある場合は避ける |
| 「最新」 | 公開時点では最新でも、すぐ古くなる可能性 |
| 「完全」「完璧」 | 実際には制限がある場合が多い |

## 6. 文章構成のガイドライン

### 導入文

- 記事の概要や読むメリットを簡潔に示す
- 2〜3文程度で完結させる

### 本文

- 見出しを適切に使い、構造を明確にする
- 箇条書きを活用して可読性を高める
- コードや具体例を交えて説明する

### 結び

- 記事のポイントを簡潔にまとめる
- 次のアクションや関連情報への誘導を含める
