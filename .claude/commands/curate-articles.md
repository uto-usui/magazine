# 記事キュレーション

このコマンドは、過去のニュースレター（`newsletters/`）から指定期間の記事をピックアップし、UXエンジニアや読者が特に興味を持ちそうな記事を選定してまとめます。

## 引数

**$ARGUMENTS**: 対象期間を自然言語で指定

例:
- `今週` - 直近7日間のニュースレター
- `1月15日から20日` - 指定した日付範囲
- `最新3回分` - 直近3つのニュースレター
- `1月` - 2026年1月全体
- `先週` - 7〜14日前
- 引数なし - 直近2週間をデフォルトとする

## 処理手順

### 1. 対象ニュースレターの特定

1. **ニュースレター一覧を取得**
   ```bash
   ls -1 newsletters/[0-9]*.md 2>/dev/null | sort -r
   ```

2. **引数を解釈して日付範囲を決定**
   - `$ARGUMENTS` が指定されている場合、自然言語を解釈して日付範囲に変換
   - 未指定の場合は直近2週間をデフォルトとする
   - ニュースレターのファイル名（`YYYY-MM-DD-HHmmss.md`）から日付を抽出して照合

3. **対象ファイルを確定**
   - 日付範囲内のニュースレターファイルをリストアップ
   - 対象が0件の場合はエラーメッセージを表示して終了

### 2. 記事の抽出

対象ニュースレターから全記事を抽出：

1. **各ニュースレターファイルを読み込む**（Readツール）

2. **記事情報を抽出**（正規表現またはマークダウン解析）
   - タイトル（`### [タイトル](URL)` 形式）
   - 出典・公開日・カテゴリ（`> **出典**: ... | **公開日**: ... | **カテゴリ**: ...`）
   - 3行まとめ
   - 詳細解説

3. **記事リストを作成**
   - 重複チェック（同じURLの記事は除外）
   - 元のニュースレター日付を記録

### 3. 記事の選定（Claudeによる自動選定）

抽出した記事から、以下の基準でUXエンジニアが特に興味を持ちそうな記事を選定：

**選定基準**:
- **実践的価値**: 実務にすぐ活かせる知見や手法が含まれている
- **技術的深さ**: 単なるニュースではなく、技術的な洞察がある
- **UXエンジニアリング視点**: デザインとエンジニアリングの橋渡しや、それぞれに関連
- **トレンド性**: 業界で注目されているトピック
- **独自性**: 他では得られない視点や情報

**選定数**:
- 抽出記事が10件以下: 全て選定
- 11件以上: 品質の高い7〜10件を選定

### 4. キュレーション記事の生成

以下のフォーマットでMarkdownファイルを生成：

```markdown
# [期間を表すタイトル] ピックアップ

**作成日**: YYYY-MM-DD
**対象期間**: [解釈した期間を自然な日本語で]

---

### [記事タイトル](元記事URL)

> **出典**: フィード名 | **公開日**: YYYY-MM-DD | **カテゴリ**: xxx

-  ポイント1
-  ポイント2
-  ポイント3

[元のニュースレターの詳細解説をベースに、読み物として自然な文章で。必要に応じて補足や新たな視点を追加]

> **編集部より**: [どのようにどんな人がいつこれを役立てられるか or 違う切り口で評価 or 合わせて知りたい概念や知識]

---

（選定記事ごとに繰り返し）

---
```

**タイトル例**:
- 「今週のピックアップ」
- 「1月後半のピックアップ」
- 「直近2週間のピックアップ」

### 5. ファイル出力

生成したキュレーション記事を保存：

- **出力先**: `newsletters/pickup/YYYY-MM-DD-HHmmss.md`
- YYYY-MM-DD: 現在の日付
- HHmmss: 現在時刻（重複防止）

```bash
# 現在日時を取得してファイル名を生成
date "+%Y-%m-%d-%H%M%S"
```

### 6. 完了報告

- 作成したファイルのパスを報告
- 対象ニュースレター数と選定記事数を報告
- 選定した記事のタイトル一覧を表示

## 使用例

```
/curate-articles 今週
→ 直近7日間のニュースレターから記事をキュレーション

/curate-articles 1月15日から20日
→ 2026-01-15 〜 2026-01-20 の記事をキュレーション

/curate-articles 最新3回分
→ 直近3つのニュースレターから記事をキュレーション

/curate-articles
→ デフォルトで直近2週間の記事をキュレーション
```

## 注意事項

- 対象期間にニュースレターがない場合はエラーメッセージを表示
- 重複記事（同じURL）は自動的に除外
- 元の「読みどころ」を尊重しつつ、「編集部より」で選んだ理由をひとこと添える
- 読み物として自然な流れを意識する
