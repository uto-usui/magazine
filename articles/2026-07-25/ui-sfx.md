## Give your product  
a sound language.

Use live synthesis on the web or copy all 936 tiny MP3 and Ogg files into any native, game, or media project. One-shots end automatically. Loops return a control you stop when the interface state resolves.

app.tslive example

import { createUISFX } from 'uisfx'

const ui = createUISFX({
  pack: Choose a sound feel
})

ui.play(Choose a one-shot sound)
const task = ui.play(Choose a looping sound)
task?.stop()

Change the green values, then run them.
