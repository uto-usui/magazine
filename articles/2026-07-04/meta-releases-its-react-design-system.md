**IN BRIEF:**

-   [Storybook has introduced first-class support for TanStack projects](https://storybook.js.org/blog/storybook-for-tanstack-react/) in the React ecosystem, including Router, Start, and Query.
    
-   Vercel continues to tease Next.js 16.3 (now in preview) with a look at [Turbopack progress](https://nextjs.org/blog/next-16-3-turbopack) and [AI-related improvements](https://nextjs.org/blog/next-16-3-ai-improvements).
    
-   Vercel has also [introduced _Vercel Services_](https://vercel.com/blog/vercel-services-run-full-stack-on-vercel). It provides a way to run multiple frameworks in one project, e.g. a Next.js frontend and a backend that might well be built in Python, Go, or Rust.
