“AI coding agents are bringing some of that interaction model back. You can describe an outcome and let the agent decide which commands to run, which files to change and which tests to execute. You no longer have to operate the software step by step, but a familiar design problem comes back in another form: What did the system understand? What is it doing? What has it changed? What can I stop? What should I review?

The interface is no longer just something we operate; it can act.”
