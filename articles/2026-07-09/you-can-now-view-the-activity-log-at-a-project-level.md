Project Settings now includes its own project-specific A[ctivity Log](https://vercel.com/docs/activity-log). This view pulls the relevant user events from the Activity Log in Team Settings. Review project-level activity without leaving your project settings.

Visit [your project settings](https://vercel.com/d?to=%2F%5Bteam%5D%2F%5Bproject%5D%2Fsettings%2Factivity) to try it out.
