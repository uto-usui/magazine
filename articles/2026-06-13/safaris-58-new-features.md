⚡️ IN BRIEF

-   📊 Google has [improved its _Baseline Checker_ tool](https://web.dev/blog/baseline-ga-checker-update). You can now find the right Baseline target for your site without exporting data from _Analytics_ first.
    
-   🏆 [Nominations for the _Tiny Awards_](https://tinyawards.net/) are now open — they celebrate the best of the small, poetic, creative, handmade web.
    
-   👍 CodePen creations [made using the new 2.0 editor](https://blog.codepen.io/docs/pens/deployment/) can now [become live, deployed sites](https://bsky.app/profile/codepen.io/post/3mnfgn4oxiy2d).
    
-   🟩 Enjoy Wordle? What about [a CSS version](https://css-questions.com/css-wordle) in which you have to guess the correct CSS feature? (It's very tough!)
