🛠  Code, Tools & Libraries

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/c9w5mttaisyanqcj3n5c.jpg)](https://visx.airbnb.tech/)

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/bokip5akj9lnpb2y87a5.jpg)](https://gre.github.io/bezier-easing-editor/)

-   [bezier-easing-editor 1.1](https://github.com/gre/bezier-easing-editor) _(above)_ – React component for visually editing Bézier curves. [Live demo.](https://gre.github.io/bezier-easing-editor/)
    
-   📺 [React Lite YouTube Embed 3.6](https://github.com/ibrahimcesar/react-lite-youtube-embed) – A tiny, privacy-friendly way to embed YouTube videos without a performance hit.
    
-   [react-native-network-logger 3.0](https://github.com/alexbrazier/react-native-network-logger) – HTTP traffic monitor/request logger for React Native with in-app viewer for iOS and Android.
    
-   [react-native-compressor 2.0](https://github.com/numandev1/react-native-compressor) – Compress images, videos and audio prior to upload, like many social apps do.
    
-   [React Native Testing Library 14.0](https://github.com/callstack/react-native-testing-library/releases/tag/v14.0.0) – Note that React 19+ and React Native 0.78+ are now required.
    
-   [react-redux-firebase 4.0](https://github.com/prescottprue/react-redux-firebase) – Redux bindings for Firebase. Now supports React 19.
    
-   [MUI (Material UI) 9.1.0](https://github.com/mui/material-ui/releases/tag/v9.1.0) – The component suite adds support for `prefers-reduced-motion`.
    

📢  Elsewhere in the ecosystem

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/ik3o5cphjgwepp8vokto.jpg)](https://vorpus.github.io/performativeUI/)

-   At WWDC this week, Apple [released the beta of Safari 27](https://webkit.org/blog/17967/news-from-wwdc26-webkit-in-safari-27-beta/) and it's packed with features, including customizable `<select>` elements, scroll anchoring, and an all-new standards-compliant [ESM loader](https://webkit.org/blog/17967/news-from-wwdc26-webkit-in-safari-27-beta/#javascript).
    
-   Get ready for your Electron apps to become faster! [Electron 43 is now in beta](https://github.com/electron/electron/releases/tag/v43.0.0-beta.1) with the main process booting from an embedded Node.js startup snapshot and bundles cached as V8 bytecode.
