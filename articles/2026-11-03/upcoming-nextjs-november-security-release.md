Next.js is preparing a scheduled security release for **Tuesday, November 3, 2026**. This advance notice gives teams time to plan upgrades before patches are published.

## [Copy link to heading](#upcoming-november-release)Upcoming November release

The November 3 release will address seven medium vulnerabilities in Next.js. We will publish the full advisories alongside the release, including impact, affected versions, and upgrade instructions. We recommend upgrading to a patched version once the release is available.

## [Copy link to heading](#our-security-program)Our security program

We work with security researchers to secure Next.js and other open source frameworks through [Vercel's Open Source Bug Bounty](https://hackerone.com/vercel). Anyone interested in contributing to the security of eligible frameworks is encouraged to participate there.

Any questions or concerns regarding our security programs or vulnerability management can be sent to [security@vercel.com](mailto:security@vercel.com).
