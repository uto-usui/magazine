[Do We Still _Need_ Build Tools for Frontend Dev?](https://olliewilliams.xyz/blog/no-build/ "olliewilliams.xyz") — A feature-by-feature audit of what build tools still do for us in 2026. Vendor prefixing and ES5 transpiling are becoming obsolete and Sass features are largely absorbed into CSS, but bundling and minification remain relevant. An honest take on where 'no-build' falls apart.

⚡️ IN BRIEF

-   📁 [Cloudflare has launched 'Drop'](https://www.cloudflare.com/drop/), a way to quickly get a site live by dropping a folder or ZIP onto a page, similar to [Netlify's service of the same name](https://app.netlify.com/drop).
    
-   🦊 Mozilla is trying [a two-week release cadence for Firefox](https://groups.google.com/a/mozilla.org/g/dev-platform/c/qlaQ1YSlOP8?pli=1) (down from four) from this September.
    
-   📑 The first [public working draft of CSS Linked Parameters](https://www.w3.org/TR/2026/WD-css-link-params-1-20260714/) proposes passing values (like theme colors) into linked resources (e.g. SVGs), exposed there as environment variables.
    
-   📵 A proposed California law [may force apps to drop 'addictive' features](https://www.sfgate.com/politics/article/meta-social-media-teenagers-22337724.php) like infinite scroll and autoplay for under-16s.
    
-   🌐 Vint Cerf, the 'father of the internet', [is retiring](https://techcrunch.com/2026/06/30/the-father-of-the-internet-is-finally-retiring/), capping one of tech's most influential careers.
