⚡️ IN BRIEF

-   🦊 Firefox now ships a major version every two weeks, and [Firefox 155 landed yesterday](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/155) with a big CSS haul: `attr()` in _any_ property, plus `progress()`, `alpha()` and `font-width` (_the new name for `font-stretch`_).
    
-   🚫 It finally happened: [Google has removed all remaining Manifest V2 extensions from the Chrome Web Store](https://webiterate.dev/google-removed-extensions-ublock-origin-108/), uBlock Origin included.
    
-   ✨ Rachel Andrew rounds up [what's new to the web platform in August](https://web.dev/blog/web-platform-08-2026), a good month for Baseline with the `text-box` properties leading the way.
    
-   📱 Firefox on iOS has [added a built-in, opt-in ad blocker](https://blog.mozilla.org/en/firefox/ad-blocker-on-ios/), built on WebKit's Content Blocker API and the EasyList filter list (_no extension required_).
    
-   📏 [CSSUnits.com](https://cssunits.com/) provides an explainer for every unit in CSS.

🕰️ A Trip Down Memory Lane

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/oumji2ws7amzmk1duqau.jpg)](https://contemporary-home-computing.org/prof-dr-style/)

In Olia Lialina's 2010 essay, [Prof. Dr. Style: Top 10 Web Design Styles of 1993](https://contemporary-home-computing.org/prof-dr-style/), you can take a trip back to the earliest days when people were barely beginning to consider 'web design' a thing, having few features at their disposal to add any flair.

The author touches on features that gradually appeared over the following years, like animated GIFs, tables, and even background colors (that could be specified by the page author, not just the end viewer).

⭐ If you like stuff like this and want to branch out a bit further than 1993, the [Web Design Museum](https://www.webdesignmuseum.org/all-websites) is dedicated to preserving screenshots of the Web over its first couple of decades.
