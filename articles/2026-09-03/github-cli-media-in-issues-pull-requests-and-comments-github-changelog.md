The ability to use [GitHub CLI and add Media in issues, pull requests, and comments](https://github.blog/changelog/2026-09-01-github-cli-media-in-issues-pull-requests-and-comments/) is an absolute game-changer for people working in AI & Design Systems.

Throughout [our course](https://aianddesign.systems/) (and especially in Chapter 2) we talk about the fundamental shift of how git and services like GitHub are used. It is SO POWERFUL for someone on a product team to capture (manually or using tools like [Playwright](https://playwright.dev/), which we cover in the course) and effortlessly dual-file a visual bug back into the design system repository.

I don't use game-changer that often, but historically design system teams have been fielding shit like ""This looks broken in our environment" with no additional context. So to receive a detail-rich summary AND real screenshots of the issue is genuinely a game-changer for design systems teams.
