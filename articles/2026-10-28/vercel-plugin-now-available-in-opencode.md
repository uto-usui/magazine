The [Vercel Plugin](https://vercel.com/plugin) is now available in [OpenCode](https://opencode.ai/).

The plugin provides on-demand guidance on Vercel APIs and recommended patterns, with [skills](https://vercel.com/docs/agent-resources/vercel-plugin#available-skills) for AI SDK, Vercel Functions, Workflow, and more.

It also includes specialist agents for deployment, performance optimization, and AI application design. Use `/vercel:deploy` to deploy projects and `/vercel:env` to manage environment variables.

The plugin requires OpenCode 2. To install it, run this command in your terminal:

```
opencode plugin add github:vercel/vercel-plugin
```

Install the Vercel Plugin in OpenCode 2.

Then run `/mcps` in OpenCode, select **vercel**, and sign in to connect the [Vercel MCP server](https://vercel.com/docs/agent-resources/vercel-mcp) to your account.

Learn more in the [Vercel Plugin documentation](https://vercel.com/docs/agent-resources/vercel-plugin#install-in-opencode).
