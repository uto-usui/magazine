## Connect your AI agent

Free with any Craftwork account. Takes about a minute

[Connect your agent](https://craftwork.design/mcp)

1.  1
    
    Run one command
    
    Paste it into the terminal on the computer where you build.
    
    `npx -y @craftwork-design/wizard@latest`
    
2.  2
    
    Your agents learn Craftwork
    
    It adds the Craftwork server and the design skill to every agent it finds.
    
    -   Claude Code
    -   Cursor
    -   Codex
    -   Lovable
    
3.  3
    
    Ask for a page
    
    It picks fonts, icons and components from Craftwork and keeps one style.
    
    Make a landing page for my coffee brand with Craftwork fonts and icons
