The [Overview tab](https://vercel.com/d?to=%2F%5Bteam%5D&title=Overview) in the dashboard now lets you choose which metric appears on each project card.

Project cards used to show a fixed Real Experience Score in the top right, but not everyone on your team watches the same signal. You can now swap that slot for whichever metric matters for that project. A security-sensitive project can show firewall activity, while a marketing site project shows traffic.

### [Copy link to heading](#available-widgets)**Available widgets**

-   **Firewall:** allowed requests, denied requests
    
-   **Observability:** alerts, edge requests, function invocations, error rate
    
-   **Speed Insights:** Real Experience Score, LCP, CLS
    
-   **Web Analytics:** visitors online, visitors, page views
    

### [Copy link to heading](#pick-per-project)**Pick per project**

Open the switcher in the top right of any project card. The menu shows the current value for each available metric. When you select one, your choice is saved for that project and follows your account across refreshes and devices.

### [Copy link to heading](#enable-features-from-the-card)**Enable features from the card**

If a project does not have a feature enabled, you can start the enable flow from the widget menu without leaving the Overview tab. This is available for Speed Insights Plus, Web Analytics, and alerts.

## [Copy link to heading](#get-started)Get started

Open your [team’s Overview tab](https://vercel.com/d?to=%2F%5Bteam%5D&title=Team+Overview) and use the switcher on any project card.
