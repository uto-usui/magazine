You can now use [fx](https://fx.sh/), our open-source coding agent harness, in [T3 Code](https://t3.codes/) on web, desktop, and mobile.

T3 Code is an open-source control plane for coding agents, allowing you to add agents like fx as providers for your coding sessions. The built-in fx provider supports Supervised and Auto modes, along with the models and skills you already use with fx.

Using fx as a coding agent in T3 Code.

Get started by [installing fx](https://fx.sh/docs/getting-started/installation) and [setting up your model provider](https://fx.sh/docs/getting-started/authentication#model-providers). Then [download T3 Code](https://t3.codes/download) and add fx from **Settings > Providers > Add provider**.
