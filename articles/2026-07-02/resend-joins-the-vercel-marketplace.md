[Resend](https://vercel.com/marketplace/resend) is now available on the [Vercel Marketplace](https://vercel.com/marketplace), allowing Vercel teams to send emails from their applications without managing any infrastructure.

This integration helps developers start sending messages within minutes, build emails as React components, and track delivery events in real time.

Key capabilities include:

-   Send transactional and marketing emails through an API or SMTP relay
    
-   Build email templates as React components with [React Email](https://react.email/docs/integrations/resend)
    
-   Track opens, clicks, bounces, and deliveries with real-time webhooks
    
-   Use the [Chat SDK adapter](https://chat-sdk.dev/adapters/vendor-official/resend) to send emails with your agent
    

Get started with [Resend](https://vercel.com/marketplace/resend) on the Vercel Marketplace or install using Vercel CLI:  

```
vc i resend -m domain=example.com
```
