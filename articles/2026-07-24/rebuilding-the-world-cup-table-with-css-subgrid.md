[Return of CSS Outline](https://www.morganwebdev.org/posts/outline-back/ "www.morganwebdev.org") — Makes the case for keeping focus outlines, a small but important accessibility detail. Plenty of sites still ship with `outline: 0`, found in old CSS resets, often leaving keyboard users unable to see what's focused — despite [`:focus-visible`](https://developer.mozilla.org/en-US/docs/Web/CSS/:focus-visible) making this a solved problem.
