[Not All Browser APIs are "Web" APIs](https://frontendfoc.us/link/179171/web "polypane.app") — An interesting look at how some of the most popular APIs _truly_ work, sharing how many of the web APIs we all use have third-party dependencies or are essentially standardized interfaces masking as vendor services. A good thing to be aware of for privacy, reliability and portability reasons.

🌐  [Introducing the <`geolocation`\> Element](https://frontendfoc.us/link/179172/web "developer.chrome.com") — As of Chrome 144, you can now use a new semantic `<geolocation>` HTML control for requesting user location data, moving away from a JavaScript-triggered prompt. There’s a [Chrome-only demo here](https://frontendfoc.us/link/179173/web). There is cross-browser interest in this approach, but some concerns and issues remain — so keep in mind it’s not a global standard just yet, though there [is a polyfill.](https://frontendfoc.us/link/179247/web)

Viana, Le, Steiner

💡 Notably, the release of Firefox 147 means **[all major browsers](https://frontendfoc.us/link/179249/web) now support [CSS Anchor Positioning](https://frontendfoc.us/link/179250/web)**, something many developers have been waiting for.
