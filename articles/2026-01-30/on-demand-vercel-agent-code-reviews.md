You can now trigger a Vercel Agent code review on demand.

When Vercel post comments on your GitHub pull request, you can now click the **Review with Vercel Agent** button from the deployment table to trigger a code review.

![](https://vercel.com/vc-ap-vercel-marketing/_next/image?url=https%3A%2F%2Fassets.vercel.com%2Fimage%2Fupload%2Fcontentful%2Fimage%2Fe5382hct74si%2F2MHGtA0LFxqL2h6x3gE5mf%2Fc5dd4600c58c0445733e7029d6c8b473%2Fslide_16_9_-_3.png&w=1920&q=75)

If you want more control, enable automatic code reviews in [Team Settings → Agent → Review PRs Automatically](https://vercel.com/d?to=%2F%5Bteam%5D%2F%7E%2Fsettings%2Fagent&title=Go+to+Vercel+Agent+Settings).

Get started by installing the [Vercel GitHub App](https://github.com/apps/vercel) or read the [documentation](https://vercel.com/docs/agent).
