May 12, 2025

Open source runs the world. The frameworks, libraries, and tools we rely on are strengthened by communities that share ideas, review code, and build in the open.

At Vercel, we want to help those communities thrive. That’s why we launched the [**Vercel Open Source Program**](https://vercel.com/docs/open-source-program): a developer initiative that gives maintainers the resources, credits, and support they need to ship faster and scale confidently.

Four times a year, we’ll welcome a new cohort of projects into the program. Members receive $3,600 in Vercel credits, perks from partners, and a dedicated Slack space to learn from one another.

Today we are announcing this spring's cohort.

### [Link to heading](#vecto3d)Vecto3d

Vecto3d converts your SVGs into 3D models. Since its launch, the project has gotten over 40K site visits and over 1,000 stars on GitHub. Unlike other SVG to 3D model converters, Vecto3d doesn’t charge for exporting.

### [Link to heading](#script-kit)Script Kit

Script Kit is a desktop app for launching scripts. It ships with an SDK to help simplify desktop/api actions and includes a custom set of prompts to handle user input/output. With over 8K commits across project repos and an existing large community, Script Kit is a thriving open source project.

### [Link to heading](#lenis)Lenis

Lenis, with 33K weekly npm downloads and 10K GitHub stars, is a lightweight, robust, and performant smooth scroll library. Designed by [@darkroom.engineering](https://x.com/darkroomdevs) for effortless integration and modern browser optimization, Lenis makes it easy to add smooth scrolling effects-like parallax and WebGL syncing-to any website.

### [Link to heading](#fumadocs)Fumadocs

Fumadocs is a beautiful documentation framework for Next.js. With over 6K GitHub stars, it leverages the power of Next.js while making it easier to create high-quality documentation sites. We use it at Vercel for our [Flags SDK](https://flags-sdk.dev/), [Turborepo docs](https://turborepo.com/docs), and more.
