[Try Text Scaling Support in Chrome Canary](https://frontendfoc.us/link/179851/web "www.joshtumath.uk") — The new `text-scale` meta tag is now available for testing behind a flag in Canary. It’s designed to respect a user’s text size preferences on the web, and essentially handle scaling in a way that simply zooming often fails at. Josh sums it up: “_the `<meta name="text-scale">` tells the browser, ‘Hey, I’ve designed my website to still work if the user increases their OS text size’_”.

Josh Tumath
