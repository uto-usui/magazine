## Interesting articles that caught my attention

[Why accessible video is still not possible on Instagram](https://a11yblog.com/2025/12/15/why-accessible-video-is-still-not-possible-on-instagram/) (5min) Instagram makes billions but still ignores basic accessibility for videos: proper closed captions, audio descriptions. Features are missing, even though Meta could easily build them. But it’s unlikely to happen until the regulatory or public pressure becomes financially too great to ignore. By Chris Yoog.

[How to Respond to ‘How Are You?’ When You’re Not OK](https://time.com/7341470/how-to-respond-to-how-are-you-when-youre-not-ok/) (12min) it’s a tricky question, especially if you don’t feel okay, but don’t want to disclose it. You don’t have to say “I’m fine” when you’re not. Be honest, f it feels safe. You can try: “I’m having a hard time” or “Not great, but managing.” Choose who you open up to. Ask if they’re ready to hear it. Give people the chance to show up for you. Let them care. By Angela Haupt.

[Humanizing AI Is a Trap – NN/G](https://www.nngroup.com/articles/humanizing-ai/) it’s tempting to humanize LLMs, but, adding personality and emotions amplifies risks, from setting unrealistic expectations to adding distractions, and concerns around privacy. We should create AI as practical tools, focusing on usability and utility rather than artificial personalities.

### Fluent UI Resources (Microsoft’s design system)

If you have to design tools in the Microsoft ecosystem (PowerApp, Sharepoint, Windows) using Fluent 2, I got a couple of tools you want to bookmark:

-   Start with [the main Fluent website](https://fluent2.microsoft.design/): you can find many guidelines, tools and resources:
-   If you work on a webtool, get yourself a copy of [the Fluent 2 web Figma file](https://www.figma.com/community/file/836828295772957889)
-   Then open [the theme designer plugin](https://www.figma.com/community/plugin/1552432883348157011/fluent-theme-designer) and follow the instructions to brand it automagically to your main brain color (so much time saved):
-    If you work with a native windows tool, get a copy of this [Windows UI kit](https://www.figma.com/community/file/1440832812269040007) (the Theme plugin doesn’t work with this one though):
-   If you need icons, I really like this plugin: [Fluent Icons](https://www.figma.com/community/plugin/1510155308259876731/fluent-icons)
-   If you want to play with the components to get a feeling of how they work, check the web component documentation: [Storybook Fluent 2 Components](https://storybooks.fluentui.dev/web-components/?path=/docs/concepts-introduction--docs)
-   Also, Microsoft has a nice accessibility documentation components: [Accessible design toolkit](https://www.figma.com/community/file/1327037919540849715)
-   And, shameless plug, if you don’t like Microsoft’s one, you can use my [Web Accessibility Toolkit for Designers](https://shop.stephaniewalter.design/b/accessibility-interactions-designer-checklist-annotation-kit), that comes with a designer’s comprehensive checklist, and, a A4 poster with a “Minimum accessibility baseline” A4 poster you can print for your office
