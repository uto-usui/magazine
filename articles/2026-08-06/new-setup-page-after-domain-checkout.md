Buying a domain on Vercel now takes you to a setup page that tracks registration live, with direct paths to deploy a new project, connect an existing one, proxy or redirect a site you already run, or set up email.

![](https://vercel.com/vc-ap-vercel-marketing/_next/image?url=https%3A%2F%2Fassets.vercel.com%2Fimage%2Fupload%2Fcontentful%2Fimage%2Fe5382hct74si%2F2Vh0cthbeTKpjT5PRCn0UI%2Ff8e4e73503838bb1e089eaf43f2420b1%2F1b.png&w=1920&q=75)![](https://vercel.com/vc-ap-vercel-marketing/_next/image?url=https%3A%2F%2Fassets.vercel.com%2Fimage%2Fupload%2Fcontentful%2Fimage%2Fe5382hct74si%2F3Lve7qYEb5nqTR8bxCjX0d%2F2c2c5c2e85915cc1ecb4a1fb1327dba6%2F1.png&w=1920&q=75)

Registration can take a few minutes. Each setup action unlocks as soon as the domain is ready. If registration fails, the page shows what went wrong and the status of your refund.

## [Copy link to heading](#deploy-a-new-project-or-connect-an-existing-one)Deploy a new project or connect an existing one

**Deploy something** opens project creation with the domain preselected. Connect a Git repository, prompt with v0, or start from a template, and the domain is attached when the project deploys.

**Connect an existing project** attaches the domain to a project you pick from your team.

![](https://vercel.com/vc-ap-vercel-marketing/_next/image?url=https%3A%2F%2Fassets.vercel.com%2Fimage%2Fupload%2Fcontentful%2Fimage%2Fe5382hct74si%2F6KG2GtT19EOAcPT7FfRStt%2F74384bb3c4e9c55155820a4877cf5fc4%2F2b.png&w=1920&q=75)![](https://vercel.com/vc-ap-vercel-marketing/_next/image?url=https%3A%2F%2Fassets.vercel.com%2Fimage%2Fupload%2Fcontentful%2Fimage%2Fe5382hct74si%2F1TMpvl5KrC1mJ7SjyLmA4K%2F2bb61488ea7786e350a7d3a474a788ce%2F2.png&w=1920&q=75)

## [Copy link to heading](#proxy-or-redirect-a-site-you-already-run)Proxy or redirect a site you already run

Enter an origin to proxy, and traffic to the domain routes through Vercel's CDN and Firewall to your existing site. Enter a URL to redirect, and visitors are forwarded there. In both cases, Vercel creates a project to handle the routing and configures it for you.

![](https://vercel.com/vc-ap-vercel-marketing/_next/image?url=https%3A%2F%2Fassets.vercel.com%2Fimage%2Fupload%2Fcontentful%2Fimage%2Fe5382hct74si%2F2WW0WsqI7jTrF5ea9OdD2Y%2F0e2229a5059c76509b5cfcd7cb137d02%2F3b.png&w=1920&q=75)![](https://vercel.com/vc-ap-vercel-marketing/_next/image?url=https%3A%2F%2Fassets.vercel.com%2Fimage%2Fupload%2Fcontentful%2Fimage%2Fe5382hct74si%2FgynQLFJwFBjpZmY4aJwF2%2Fea17b62d3293a2508d623b9240fc553d%2F3.png&w=1920&q=75)

## [Copy link to heading](#set-up-email-with-dns-presets)Set up email with DNS presets

Choose your email provider and Vercel adds the DNS records it needs. Presets are available for Google Workspace, Outlook, iCloud, Proton Mail, Zoho, Mailgun, and ImprovMX. There's also a preset for using the domain as your Bluesky handle.

![](https://vercel.com/vc-ap-vercel-marketing/_next/image?url=https%3A%2F%2Fassets.vercel.com%2Fimage%2Fupload%2Fcontentful%2Fimage%2Fe5382hct74si%2F2wQWlOXc9gGTttmhqXmbTj%2F6ede81169f3da74c5c55969054e9da96%2F4b.png&w=1920&q=75)![](https://vercel.com/vc-ap-vercel-marketing/_next/image?url=https%3A%2F%2Fassets.vercel.com%2Fimage%2Fupload%2Fcontentful%2Fimage%2Fe5382hct74si%2F52PttYWZ8i5oCLkRfGOQg%2Fa94ba55759ff294710fe88c7d6cec916%2F4.png&w=1920&q=75)

If you'd rather configure records yourself, **Manage DNS records** opens the domain's DNS records page.  
Search for a domain at [vercel.com/domains](https://vercel.com/domains) to get started.
