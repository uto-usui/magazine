## Notes

Pick almost any control in a design tool and you’ll find a file format underneath it. Gradients just make it easy to see: every tool ships the same three or four – linear, radial, angular, maybe diamond – and all of them are projections, colour assigned by where a pixel lands on an invisible axis, never by the thing you actually drew. The moment the artwork curves, the tool stops looking at it. The editor above starts from the opposite premise – colour belongs to the drawing – and everything else about it stays deliberately boring yet highly interactive and precise: every stop drags, nudges and types to the exact percent – more editing than that little axis with handles will ever hold.

None of it is technically hard. It wasn’t hard in 2017, when this editor was created, and it isn’t hard now. What’s hard is refusing a ceiling: tools implement what the export format can already say, and stop – so the colour panel is a diagram of spec syntax with handles on it. A tool built that way can standardise; it can’t propose. A whole industry draws with the same things not because anyone chose them, but because nobody was choosing.

That’s my worry about this moment. We pour everything into tools that imagine _for_ us while the tools we imagine _with_ sit unfinished – not solved and superseded, just abandoned. When a prompt outperforms the tool, that isn’t the machine’s triumph; it’s the instrument’s failure. One gradient held this much unclaimed ground. Think what the rest of the toolbox is holding.
