Every [Vercel Sandbox](https://vercel.com/sandbox) now includes 64 GB of storage, up from 32 GB. This includes sandboxes created from a [Vercel Managed Image](https://vercel.com/changelog/vercel-sandbox-managed-images) or custom image, as well as those configured with the deprecated `runtime` property.

The additional space provides more room for large repositories, dependencies, build artifacts, data workloads that spill to disk, and storage-intensive agent tasks.

Learn more about [Sandbox images](https://vercel.com/docs/sandbox/concepts/images) in the documentation.
