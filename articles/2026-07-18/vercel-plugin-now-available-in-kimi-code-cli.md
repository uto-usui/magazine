The [Vercel Plugin](https://vercel.com/plugin) is now available in the [Kimi Code CLI](https://www.kimi.com/code).

Kimi Code can now draw on Vercel platform knowledge on demand, with skills for Next.js, AI SDK, Vercel Functions, and more. The Vercel Plugin also helps Kimi Code stay up to date with the latest Vercel APIs and recommended patterns.

To install it, upgrade to the latest Kimi Code CLI and select the Vercel Plugin from the Third-party section of the `/plugin` menu.
