[Vercel Sandbox](https://vercel.com/docs/sandbox) no longer bills for data it downloads from the internet. Installing packages, cloning a Git repository, or pulling artifacts and datasets from an external source does not count toward Sandbox Data Transfer usage.

Traffic received on a Sandbox's exposed ports is still billable, as is outbound traffic the Sandbox sends to the internet. Pricing for Active CPU, Provisioned Memory, Snapshot Storage, and Sandbox Creations is unchanged.

See the [pricing documentation](https://vercel.com/docs/sandbox/pricing) for the full breakdown.
