📢  Elsewhere in the ecosystem

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/zlnzm7dkbt1k4t7caceg.jpg)](https://results.stateofreactnative.com/en-US/)

-   [The results of the _State of React Native 2025_ survey](https://results.stateofreactnative.com/en-US/) have been released by Software Mansion and Devographics. There's a ton to dig into, largely around the use of various techniques and libraries, but it's neat to see the majority of React Native developers have [already transitioned to the New Architecture.](https://results.stateofreactnative.com/en-US/react-native-architecture/)
    
-   [Bun v1.3.10 was released](https://bun.com/blog/bun-v1.3.10) with a `build --compile --target=browser` [feature](https://bun.com/blog/bun-v1.3.10#compile-target-browser-for-self-contained-html-output) to produce self-contained HTML files containing all assets inlined, including complete client-side-only React apps.
    
-   [Deno 2.7 was also released](https://deno.com/blog/v2.7) - no specific React related features, but the alternative JS runtime makes its Temporal API support stable, supports Windows on ARM, has some new ways to run subprocesses, and continues to improve its Node.js compatibility.
    
-   Tailwind CSS 4.2, released last week, has [four new color palettes in its default theme](https://superhighway.dev/tailwind-v4-2-new-palettes): mauve, olive, mist, and taupe.
    
-   [The Navigation API is now Baseline Newly Available](https://web.dev/blog/baseline-navigation-api?hl=en) across all major browsers.
