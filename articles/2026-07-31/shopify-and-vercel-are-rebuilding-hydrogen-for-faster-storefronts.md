## [Copy link to heading](#shopify-and-vercel-)Shopify and Vercel

-   Open source and runtime agnostic, runs anywhere JavaScript does
    
-   Standard Actions brings agentic commerce to every storefront
    
-   Feature development cut from months to a week for retailers like Global Retail Brands
    

[Shopify](https://www.shopify.com/) powers commerce for millions of merchants worldwide, and Hydrogen is its framework for building headless storefronts. The Shopify team is partnering with Vercel to rebuild Hydrogen from the ground up. The new version is open source and runtime agnostic so developers can build with Next.js, Nuxt, Svelte, or any framework they choose. As a result, storefronts that once required custom glue code now ship with best practices built in, from type-safe API clients to cart state in a single import.
