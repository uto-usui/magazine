**IN BRIEF:**

-   [TypeScript 7.0](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/), the 10x faster Go-powered version of the TypeScript compiler, has been released. With no programmatic API yet, however, [6.0 is still recommended](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/) for many frontend frameworks.
    
-   [Vercel has acquired](https://vercel.com/blog/vercel-acquires-better-auth) the team behind [Better Auth](https://better-auth.com/), the popular authentication library. Flavio Copes [has a quick intro post](https://flaviocopes.com/better-auth/) if you're not familiar with it.
    
-   On Reddit, `/r/reactjs` discussed [React patterns they stopped using after working on larger projects](https://www.reddit.com/r/reactjs/comments/1uqqy52/whats_one_react_pattern_you_stopped_using_after/). `useEffect` came up a _lot_.
    
-   The [React Navigation](https://reactnavigation.org/) team shares [a progress update on React Navigation 8.0](https://reactnavigation.org/blog/2026/07/08/react-navigation-8.0-july-progress/) including Suspense-enabled navigation.
    
-   There's [an official RFC for WebSocket support in Next.js Route Handlers](https://github.com/vercel/next.js/discussions/95514).
    

[React Forms Done Right](https://upskills.dev/tutorials/react-forms-done-right "upskills.dev") — An interactive dive into web forms, starting with zero-JS HTML forms and moving through React 19 native form actions to using [TanStack Form](https://tanstack.com/form/latest) with Zod. Complete with several demos.

📢  Elsewhere in the ecosystem

[![](https://res.cloudinary.com/cpress/image/upload/w_1280,e_sharpen:60,q_auto/mxo6pseu9mmn7kprwqh2.jpg)](https://fonts.google.com/specimen/Geist+Pixel)

-   🔠 [Geist Pixel](https://vercel.com/font?type=pixel), the latest member of Vercel's _Geist_ family of fonts, is [now available to use on Google Fonts](https://fonts.google.com/specimen/Geist+Pixel?preview.script=Latn). _Yes, I have Gen Alpha kids._
    
-   [npm v12 has shipped](https://github.blog/changelog/2026-07-08-npm-install-time-security-and-gat-bypass2fa-deprecation/) with lifecycle scripts and implicit node-gyp builds no longer running by default. [Here's more on the implications.](https://socket.dev/blog/npm-12)
    
-   🤖 Bun's Jarred Sumner wrote up [the story of rewriting Bun in Rust](https://bun.com/blog/bun-in-rust), an AI-powered port that will power Bun 1.4 onward.
    
-   The Ruby community has created [a great guide on how to start a Ruby meetup](https://guides.rubyevents.org/meetups/), but the advice is general enough for it to apply to React meetups too.
    
-   🤖 [Safari has introduced an MCP server](https://webkit.org/blog/18136/introducing-the-safari-mcp-server-for-web-developers/) in its latest preview to give agents control over a Safari window during debugging runs.
    
-   🕹️ [js1024, the annual 1KB code-golf competition, is open for entries](https://js1024.fun/#2026). The theme is 'dreaming', and you've got 1,024 bytes to make something neat.
