[New Things You Should Know About HTML in 2026](https://blog.master.dev/new-things-you-should-know-about-html-here-in-mid-2026/ "blog.master.dev") — HTML moves a bit slower than CSS and JavaScript, but there's plenty of new features to keep up with. Chris runs through several, including the `geolocation` element, HTML-in-Canvas, camera and mic management via `usermedia`, and the `model` element. A great way to catch up.

Chris Coyier

[Antiquated HTML Snippets and Artefacts](https://vale.rocks/posts/html-relics "vale.rocks") — A tour of various snippets of code that commonly appear in HTML, but which are largely byproducts of a bygone era and are no longer needed. Conditional comments, `X-UA-Compatible`, and `cleartype` directives all make an appearance.

Declan Chidlow

🗳️ [W3C Opens Its 2026 Community Survey](https://www.w3.org/news/2026/w3c-opens-2026-community-wide-survey/ "www.w3.org") — The W3C has launched its 2026 community-wide survey to gather input from developers and stakeholders on the future direction of its operations and web standards work.

W3C

⚡️ IN BRIEF

-   🎉 [The team behind Tailwind CSS is joining Shopify](https://tailwindcss.com/blog/tailwind-is-joining-shopify) but _"nothing changes with Tailwind CSS or any of our other open-source projects."_
    
-   📑 [Interop 2027 proposals are open until September 23](https://blogs.windows.com/msedgedev/2026/09/03/calling-for-interop-2027-proposals/) — you can nominate the cross-browser gaps that most need fixing.
    
-   🗓️ As promised, Chrome has now [moved to a two-week release cycle](https://techcrunch.com/2026/09/08/chrome-is-now-shipping-updates-every-2-weeks-as-ai-changes-the-security-landscape/), with Firefox, Edge and Brave following suit.
    
-   🖼️ JPEG XL support will [be enabled by default in Firefox 158](https://groups.google.com/a/mozilla.org/g/dev-platform/c/3YMV4MS34KA/m/8CblVBJCAAAJ).
    
-   🕵️ Years ago, a developer noticed Chrome exempted Google's own sites from the setting that wipes site data on exit (Google fixed it). Now, he claims [it's happening again as of Chrome 152](https://lapcatsoftware.com/articles/2026/9/1.html).
    
-   🏛️ InfoQ reflects on [jQuery 1.0 turning 20 years old](https://www.infoq.com/news/2026/09/jquery-20-years/) and why it remains heavily used across the Web.
    

📙 Articles, Opinions & Tutorials

[Creating a Custom Scrollbar Component in 2026](https://blog.master.dev/custom-scrollbar-component-in-2026/ "blog.master.dev") — How to approach building high-performance custom scrollbars, replacing heavy JavaScript arithmetic with modern CSS features and handling sizing and visibility entirely within the stylesheet. A clean, modern approach to a classic UI challenge.

[The Browser's Main Thread is Expensive](https://kciter.so/posts/the-expensive-main-thread/en/ "kciter.so") — A thorough look, complete with demos, at spending your main thread time well, including splitting, batching, prioritizing, and deferring tasks, then how to get work off it entirely.

Sunhyoup Lee

[CSS: The Weapon Inside Your Inbox](https://portswigger.net/research/css-the-bomb-inside-your-inbox "portswigger.net") — How CSS can be weaponized against popular webmail providers to do things it shouldn't be able to, like defacing the UI, bypassing image proxies, and building a keylogger.

Gareth Heyes

[`.name` Termination](https://neil.fraser.name/news/2026/09/03/ "neil.fraser.name") — Discusses the impending sunset of `.name`'s third-level domains and the implications for those using it for their online identity.
