Andreas Kling:

> [Ladybird is a browser with a new engine.](https://ladybird.org/posts/alpha/) The engine is our own, built from the ground up, and not a fork. The browser around it is modest, but functional.
> 
> This is an alpha, so some websites won’t work, and it will crash sometimes. When that happens, tell us!

We lost Opera as a browser engine in 2013. We lost Edge’s browser engine in 2018. Firefox has long felt like it’s teetering. Browser engine diversity has been on the decline, until now.
