The [Vercel Plugin](https://vercel.com/plugin) is now available in the [Google Antigravity](https://antigravity.google/) marketplace.

Use the Vercel Plugin to give your Antigravity agent guidance on Vercel APIs and recommended patterns, with skills for products such as [AI SDK](https://ai-sdk.dev/), [Vercel Functions](https://vercel.com/docs/functions), and [Workflow](https://useworkflow.dev/).

This demo shows an Antigravity agent using the Vercel Plugin to build and deploy a Python backend with [Vercel Sandbox](https://vercel.com/docs/sandbox):

Install the Vercel Plugin by opening **Customizations** → **Marketplace** in the Antigravity App and searching for **Vercel**, then see the [Vercel Plugin documentation](https://vercel.com/docs/agent-resources/vercel-plugin) for available skills and guidance.
