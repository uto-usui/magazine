You can now view specific error codes in runtime logs.

[Runtime logs](https://vercel.com/docs/logs/runtime) helps you view and troubleshoot errors in your applications on Vercel. In addition to the HTTP status response code, we also list the specific error code the request details panel of the runtime logs page of the Vercel dashboard.

This makes it easier to diagnose why a request failed.
