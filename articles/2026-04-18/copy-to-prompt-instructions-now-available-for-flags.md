The feature flags details page now includes copy-to-prompt instructions in the instructions pane.

﻿You or your agent can install the Flags SDK, link the project using the [Vercel CLI](https://vercel.com/docs/cli), and add the required flag definitions to the code base.

Teams that prefer manual configuration can still copy the exact flag definitions directly from the instructions pane.

Learn more about [Vercel Flags](https://vercel.com/docs).
