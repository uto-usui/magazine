A free and open source vector editing tool that looks great. Sure, Affinity is now free to everyone, but tools like Graphite will work well if you want to get away from corporate software, for example.

A handy, simple markdown/text editor that even has dictation capabilities.

There’s some unbelievably good tools in this collection and there are _loads_ to choose from. Our favourite is the [simple font file explorer](https://tools.rmv.fyi/tools/font-explorer).

Wireframes are supposed to be very lo-fi and this tool does _exactly_ that, right in your browser.

This is really cool. It’s like a web-based dashboard for Kindles (and other E Ink devices that have a browser). It’s even got a Mario game!
