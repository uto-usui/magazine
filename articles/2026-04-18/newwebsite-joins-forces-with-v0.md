v0 and new.website have joined forces to accelerate our vision of helping anyone ship complete, production-ready software with AI.

new.website was founded to make it effortless to create beautiful websites with all the tools included, from built-in forms to SEO. They’re joining the v0 team to help shape our built-in tools and integrations.

## [Link to heading](#why-new.website)**Why new.website**

The team at new.website built thoughtful primitives that exposed configuration for critical website features instead of requiring users to implement them with multiple prompts and code checks.

![](https://vercel.com/vc-ap-vercel-marketing/_next/image?url=https%3A%2F%2Fassets.vercel.com%2Fimage%2Fupload%2Fcontentful%2Fimage%2Fe5382hct74si%2F6TWzeIUaXkiae9dGMV4JZT%2F7666d8b52d7be784b906bdc53b35e0ce%2Fforms-photography-cropped.png&w=1920&q=75)

Here are examples of their built-in tooling:

-   **Built-in forms and databases**. Every site came with forms by default and every submission was automatically stored without any setup.
    
-   **Simple SEO features**. Website generation included core SEO configuration like meta tags and structure, and those settings were exposed in the UI for direct configuration.
    
-   **Content management.** Content could be edited outside the website, even when generated by an agent, which was a better user experience for long-form entries like blogs.
    

The goal of every primitive was to reduce the amount of prompting required to implement and configure baseline website functionality.

## [Link to heading](#why-v0)Why v0

new.website’s focus on built-in primitives and high-quality design output maps directly to our vision for v0. Bani and her team are joining v0 to help build out our agent capabilities, so look for core features like forms, content, and data to feel native and fully agent-aware soon.

Together with the new.website team, we're making it easier for anyone to build and deploy real software.
