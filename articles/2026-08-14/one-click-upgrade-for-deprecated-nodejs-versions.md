Team owners and members can now upgrade all projects using Node.js 20 or earlier to Node.js 24 with one click from the Vercel Dashboard.

This updates the [Node.js version in project settings](https://vercel.com/docs/functions/runtimes/node-js/node-js-versions#setting-the-node.js-version-in-project-settings). If your project also defines a version in `package.json`, you'll need to update it manually. Existing deployments are not affected.

[View and upgrade deprecated Node.js projects now.](https://vercel.com/d?to=%2F%5Bteam%5D%23upgrade-deprecated-nodejs-versions&title=Upgrade+Deprecated+Node.js+Versions)
