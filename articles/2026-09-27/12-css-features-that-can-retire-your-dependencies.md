📙 Articles, Opinions & Tutorials

[The Root Scroller and How Not to Lose It](https://polypane.app/blog/the-root-scroller-and-how-not-to-lose-it/ "polypane.app") — The ‘root scroller’ is the viewport’s scroll container and handles things like scroll restoration and collapsing mobile address bars. But common CSS patterns can hand scrolling to other elements and lose those features, as shown in this demo-packed explainer.

Kilian Valkhof

["AI, Make the Website Good"](https://www.zachleat.com/web/ai-websites/ "www.zachleat.com") — Zach argues that, no matter the tools, caring about the _quality_ of output matters more than ever. He amusingly illustrates this point by highlighting the front of house output of top AI companies.

Zach Leatherman

[Responsive `iframes` in Chrome 154](https://developer.chrome.com/blog/responsive-iframes "developer.chrome.com") — Landed in Chrome, and in preview in Edge, responsively-sized iframes are now a thing. You can set an iframe to be the size of its content, set which dimension that size is derived from, and tweak dynamically. The only catch is the embedded document must opt in.

Sebastian Benz & Bramus van Damme
