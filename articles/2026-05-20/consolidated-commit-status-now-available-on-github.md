Monorepos can now opt in to a single, consolidated commit status on pull requests instead of one commit status per project. For repos with many projects, teams can configure GitHub branch protection once, then manage which Vercel projects are required for merge in each project’s settings.

Read more about [Github Commit statuses](https://vercel.com/docs/git/vercel-for-github#commit-status) and and enable Consolidated Commit Status from your [project settings](https://vercel.com/d?to=%2F%5Bteam%5D%2F%5Bproject%5D%2Fsettings%2Fgit%23git-commits).
