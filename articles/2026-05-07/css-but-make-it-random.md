[The Importance of Native Randomness in CSS](https://frontendfoc.us/link/184775/web "css-tricks.com") — The “_deterministic by design_” nature of CSS means that achieving true randomness requires workarounds (like JavaScript, preprocessors, or server-side work). This post looks at the options, and makes the case for native variation tools that can take CSS from just a styling language into a generative layout system.

Alvaro Montoro

[Trustworthy JavaScript for the Open Web](https://frontendfoc.us/link/184778/web "hacks.mozilla.org") — Web Application Integrity, Consistency and Transparency (WAICT) is an emerging spec for verifying that the JavaScript running in a browser actually matches what the site published ([here's a deeper explainer](https://frontendfoc.us/link/184779/web)).
