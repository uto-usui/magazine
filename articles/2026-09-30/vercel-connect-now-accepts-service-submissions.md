[Vercel Connect](https://vercel.com/connect) now lets you submit your own service to the [connectors directory](https://vercel.com/connect/browse), so you no longer need to wait for Vercel to build a connector for it.

Submitting a service takes four steps:

1.  Describe your service.
    
2.  Add one or more connection methods, using OAuth or an API key.
    
3.  Verify each OAuth method by requesting a real token through a test connector.
    
4.  Send the submission for review.
    

Vercel reviews each submission before publishing it to the directory.

Get started from [Submit a Service](https://vercel.com/d?to=%2F%5Bteam%5D%2F~%2Fconnect%2Fsubmit-service) in the dashboard, or read what your service needs to support in the [documentation](https://vercel.com/docs/connect/providers).
