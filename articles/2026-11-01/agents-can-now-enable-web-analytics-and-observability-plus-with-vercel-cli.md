[Vercel CLI](https://vercel.com/cli) no longer requires an interactive terminal to enable [Web Analytics](https://vercel.com/analytics) or [Observability Plus](https://vercel.com/docs/observability/observability-plus). Agents can now turn them on for your projects without asking you to run the commands yourself.

To get started, run either command from a linked project directory:

```
vercel project web-analytics enablevercel project observability enable
```

Enabling Web Analytics or Observability Plus

Teams must already be subscribed to Observability Plus to be able to enable it for a project.

Update Vercel CLI to version 64.2.0 or later and learn more in the [Vercel CLI project documentation](https://vercel.com/docs/cli/project).
