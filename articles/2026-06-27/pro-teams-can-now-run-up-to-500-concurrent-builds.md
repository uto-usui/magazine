Pro teams can run up to 500 concurrent builds, up from 12. Teams with large repos can ship faster without waiting on queued builds. On-demand concurrent builds are enabled by default for Pro and Enterprise, and you're billed only for the build minutes you use.

Learn more about [on-demand concurrent builds](https://vercel.com/docs/builds/managing-builds#on-demand-concurrent-builds).
