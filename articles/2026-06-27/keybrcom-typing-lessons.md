## Learn to Type Faster

This web application will help you to learn _touch typing_ which means typing through muscle memory without using your eyesight to find the keys. It can improve your typing speed and accuracy dramatically. The opposite is _hunt and peck typing_, a method of typing in which you look at the keyboard instead of the screen, and use only the index fingers.

This is a short tutorial that will explain how this application works.

You can use the left and right arrow keys to navigate through these slides.
