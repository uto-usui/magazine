[The Most-Seen UI on the Internet? Redesigning Turnstile and Challenge Pages](https://frontendfoc.us/link/181513/web "blog.cloudflare.com") — We’ve all seen Cloudflare’s verification widget, or challenge pages — _heck, you may well have seen them already today_. Cloudflare serves these over 7.5 billion times each day, so making any design changes requires a lot of care. This is a detailed look at how they do just that, while maintaining accessibility and security standards.

Bacevicius, Foppa, Elmore (Cloudflare)

Frontend Masters

[Chrome is Moving to a Two-Week Release Cycle](https://frontendfoc.us/link/181514/web "developer.chrome.com") — Starting in September, in an effort “_to match the demands of a modern web_”, Chrome will shift from a four-week to a two-week release cadence. This change is to the stable release, with no changes announced for the Dev and Canary channels. Chrome 200 in time for the next Olympics?

Mason & Ravichandran (Chrome for Developers)

[Why is WebAssembly a Second-Class Language on the Web?](https://frontendfoc.us/link/181515/web "hacks.mozilla.org") — WASM may well have come a long way, but it remains tricky to work with huge amounts of glue code par for the course. Ryan makes the case that the WebAssembly Component Model could change this, by letting modules bind directly to browser APIs, load directly from `script` tags, and more.

Ryan Hunt

[You Can Use Newline Characters (and Tabs) in URLs](https://frontendfoc.us/link/181520/web "lemire.me") — Daniel clearly explains some of the nuances of the [WHATWG URL spec](https://frontendfoc.us/link/181521/web), revealing that browsers essentially allow for both newline and tab characters within URLs.
